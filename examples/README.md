# Configuration examples

These files are examples only and are not deployed.

- `preview.static.json` — publish `site/` as-is.
- `preview.static-spa.json` — publish `site/` and create SPA `404.html` fallback.
- `preview.command-vite.json` — run an npm build and publish `dist/`.

To use one, copy its contents into the repository-root `preview.config.json` and adjust the paths or command.
